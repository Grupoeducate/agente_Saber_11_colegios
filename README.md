# Prototipo del curso de Lectura Crítica

## Uso
1. Copie `Logogec.png` dentro de `assets/`.
2. Sirva la carpeta con un servidor web. Ejemplo: `python -m http.server 8000`.
3. Abra `http://localhost:8000`.

No abra `index.html` directamente con `file://`, porque el navegador puede bloquear la lectura de JSON.

## Contenido inicial
- Curso tipo slide/navegable.
- Carga de uno, dos o tres periodos por colegio.
- Semaforización de respuestas incorrectas.
- Ruta formativa priorizada.
- Consulta de las tres afirmaciones.
- Nueve preguntas modelo originales, una cobertura inicial de las combinaciones afirmación/componente.
- Pie permanente: Dirección de Pedagogía.
