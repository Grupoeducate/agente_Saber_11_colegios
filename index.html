Estas preguntas son ejemplos de formación docente. No son preguntas oficiales del Icfes y no agotan la afirmación ni la evidencia.

Criterio metodológico

  1. El porcentaje de respuestas incorrectas determina la semaforización.
  2. La tendencia histórica orienta la prioridad formativa.
  3. Las tareas y dificultades se presentan como referentes para formular hipótesis.
  4. La causa debe verificarse con evidencias de aula.
Resultado → prioridad → formación docente → hipótesis → verificación → decisión pedagógica.
